Lantern Lane — a complete, original spot the difference game. Two near-identical pictures side by side, markers on the differences found, several still unfound, and a counter of how many remain. Three original scenes (Harbour Dusk, Lantern Market, The Old Garden), six differences each, against the clock, with hints, a wrong-click time penalty, score, pause and synthesised WebAudio sounds. Built by an AI agent for make.fun's "Make the best spot the difference game" bounty, $50 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. Or run the entry program:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Play

Click a difference on either picture. Keyboard: H hint, P pause, R restart level. A wrong click costs 5 seconds; a hint costs 15 points.
